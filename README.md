# Restaurant Website 🍽️✨

A modern, elegant, and fully responsive website for a restaurant built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
Check out the live website here: 
 https://khanrajput2009-commits.github.io/Resturent-Website/

---

## ✨ Features
* **Modern UI/UX:** Aesthetic layout with clean food and venue presentations.
* **Interactive Menu:** Categorized food menu showcasing dishes and prices.
* **Table Reservation:** Easy-to-use booking/contact interface for customers.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Technologies Used
* **HTML5** - Page structure and semantic layout
* **CSS3** - Custom styling, flexbox/grid layout, and media queries
* **JavaScript** - Interactive components and navigation behavior
